Integrations / Figma

Create and link issues directly from Figma

Streamline work across design and engineering with the Figma plugin for Linear

Overview

Bring design and development closer together with built-in Figma tooling. Install the Linear plugin for Figma to create and link issues straight from your designs, and enable embedded previews of files inside Linear issues and documents.

Linear plugin for Figma

Open the Linear plugin to view every Linear issue linked to your Figma design. Individual frames, sections, and pages can be linked to existing issues, or you can create brand new issues right from the canvas.

Clicking an issue jumps you to its linked design and surfaces the relevant issue details, so you can navigate your designs with full context and see where work currently stands. Right from the plugin, mark an issue done or assign it to a teammate once a design is ready to build. Any status change made in Linear reflects back in the Figma plugin instantly.
