Integrations / Figma

Create and link issues
directly from Figma

Streamline work across design and engineering with the Figma plugin for Linear

Overview

Streamline design and development with built-in tooling for Figma. Install the Linear plugin for Figma to create and link issues to your designs. You can also turn on embedded previews of your designs inside Linear issues and documents.

Linear plugin for Figma

Use the Linear plugin to see every Linear issue linked to your design in Figma. Link individual frames, sections, and pages to existing Linear issues, or create new issues right from the canvas.

Selecting an issue brings you to the linked design and shows key details about it, so you can navigate your designs in context and see the current state of work. From the plugin, mark issues as done or assign them to teammates once a design is ready for development. When an issue's status changes in Linear, the plugin on Figma updates instantly to match.
